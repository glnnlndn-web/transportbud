# Transport Bud\n\nPremium transport allocation app with dark neon design.\n\n## Features\n\n- Dark mode with vibrant neon colors (cyan, pink, lime)\n- Real-time job allocations\n- Customer, driver, vehicle management\n- Allocators page with job form and active list\n- React, Tailwind CSS, Framer Motion\n- Supabase integration\n\n## Setup\n\n1. Install: `npm install`\n2. Create `.env.local` with Supabase credentials\n3. Dev: `npm run dev`\n4. Build: `npm run build`
